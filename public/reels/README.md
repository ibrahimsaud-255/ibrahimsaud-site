# مقاطع الإعلانات الطولية (٩:١٦)

هنا صور المقاطع (poster) — وهنا تُرفع ملفات الفيديو نفسها عند تجهيزها.

## الوضع الحالي

- كل مقطع في `src/lib/reels.ts` يشتغل من **قوقل درايف** (`driveId`)، وصورته المصغّرة
  محفوظة هنا (`arkan.jpg`، `btech.jpg` …) حتى تُحمَّل بسرعة وبلا اعتماد على قوقل.
- درايف يشتغل داخل الموقع، لكنه يتطلّب ضغطة ▶ داخل مشغّل قوقل ولا يشتغل تلقائياً.

## الترقية الموصى بها (تجربة تيك توك كاملة)

ارفع ملف mp4 لكل مقطع هنا، ثم في `src/lib/reels.ts` بدّل `driveId` بـ `src`:

```ts
{
  id: "arkan",
  src: "/reels/arkan.mp4",      // ← بدل driveId
  poster: "/reels/arkan.jpg",
  ...
}
```

عندها يشتغل المقطع تلقائياً وصامتاً ويتكرّر، ويظهر زر الصوت في المشغّل.

### المواصفات المثالية

- **الأبعاد:** 1080×1920 عمودي (أو 720×1280 لحجم أصغر).
- **الصيغة:** mp4 (H.264 / AAC). **الحجم:** ~3–5 ميجابايت للمقطع.
- **المدة:** 10–40 ثانية.

### أمر ffmpeg للضغط

```
ffmpeg -i الأصلي.mov -vf "scale=1080:1920" -c:v libx264 -crf 26 -preset slow -c:a aac -b:a 128k arkan.mp4
ffmpeg -i arkan.mp4 -frames:v 1 -q:v 3 arkan.jpg
```

## إضافة مقطع جديد

افتح `src/lib/reels.ts` وأضف عنصراً جديداً بالحقول: `id`، `client`، `category`،
`roles`، `desc`، و`src` (أو `driveId` / `ytId`) و`poster`.
الترتيب في الملف = الترتيب في الموقع.
