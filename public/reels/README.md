# مقاطع تجربة الريلز (أسلوب تيك توك)

ارفع هنا ملفات الفيديو العمودية اللي تظهر في «🎬 ابدأ التجربة».

## المواصفات المثالية (للسرعة والجودة)

- **الأبعاد:** 1080×1920 عمودي (أو 720×1280 لحجم أصغر).
- **الصيغة:** mp4 (H.264 / AAC).
- **الحجم:** اضغط لـ ~3–5 ميجابايت للمقطع — كل ما صغّرت، أسرع تشغيل.
- **المدة:** 10–30 ثانية مثالية.
- لكل مقطع: ملف `.mp4` + صورة `.jpg` (poster) بنفس الاسم.

### أمر ffmpeg للضغط (اختياري)

```
ffmpeg -i الأصلي.mp4 -vf "scale=1080:1920" -c:v libx264 -crf 26 -preset slow -c:a aac -b:a 128k tad-1.mp4
ffmpeg -i tad-1.mp4 -frames:v 1 -q:v 3 tad-1.jpg
```

## بعد الرفع

افتح `src/lib/reels.ts` وأضف/عدّل سطر المقطع ليستخدم `src` بدل `ytId`:

```ts
{
  id: "tad-1",
  src: "/reels/tad-1.mp4",
  poster: "/reels/tad-1.jpg",
  client: "متجر TAD",
  title: "حملة شاحن السفر",
  roles: ["فكرة", "تصوير", "مونتاج"],
}
```

تقدر تضيف حتى ~30 مقطع — كلها تظهر بالتتابع في التجربة.
