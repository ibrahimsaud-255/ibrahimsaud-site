# بوابة مواقع العملاء

ملف واحد (`gate.js`) يُضاف لأي موقع عميل، ويُدار كاملاً من **نظامك ← بوابة المواقع**.

## ماذا يفعل؟

1. **يقيس الزيارات** — كل فتح صفحة يُسجَّل (بلا أي بيانات شخصية: معرّف عشوائي فقط)
   فتعرف هل نشر العميل الموقع، ومن أي صفحة، ومن أين جاء الزوّار.
2. **يقفل الموقع عند الطلب** — الموقع يظهر كاملاً لكن **مغبّشاً**، ومع الزائر **عدسة**
   يحرّكها فتكشف ما تحتها، **وتكبر كلما ضغط أكثر**. لا تصفّح، ولا نسخ، ولا فتح روابط.
3. **زر واتساب في الزاوية** — يضغطه العميل فيصلك رسالة، ويظهر عندك في النظام
   كـ«طلب فتح» مع زر يفتح الموقع ٢٤ ساعة بضغطة.

## التنصيب (مرة واحدة)

**١) قاعدة البيانات:** لوحة Supabase ← SQL Editor ← الصق `supabase/client_sites.sql` ← Run.

**٢) في كل موقع عميل:** أضف هذا السطر داخل `<head>`:

```html
<script src="/gate/gate.js" data-site="اسم-الموقع"></script>
```

أو لموقع داخل مسار من موقع أكبر (مثل `/sarah` داخل موقع إبراهيم):

```html
<script src="/gate/gate.js" data-map='{"/sarah":"sarah","/masarak":"masarak"}'></script>
```

`data-site` / قيم `data-map` يجب أن تطابق عمود `slug` في جدول `client_sites`.

## المواقع المربوطة حالياً

| الموقع | المعرّف | مكان السطر |
|--------|---------|------------|
| منابر | `manabir` | `public/manabir/index.html` |
| إبرة سارة | `sarah` | `src/app/layout.tsx` (بخريطة المسارات) |
| التكامل المتحدة | `ilogistics` | كل صفحات `public/ilogistics/` |
| مسارك | `masarak` | `src/app/layout.tsx` (بخريطة المسارات) |

## رابط معاينتك الخاص

من النظام: بطاقة الموقع ← **معاينتي** — ينسخ رابطاً فيه مفتاحك (`?k=…`).
يفتح لك الموقع دائماً حتى وهو مقفل، ولا تُحتسب زياراتك في الإحصاءات.
المفتاح محفوظ داخل قاعدة البيانات ولا يظهر في كود الصفحة. **لا تشاركه مع العميل.**

## سلوك البوابة عند الأعطال

| الحالة | ماذا يحدث |
|--------|-----------|
| الجداول غير منصّبة بعد | الموقع **مفتوح** (لا تتعطّل مواقع العملاء) |
| انقطاع شبكة وللزائر حالة محفوظة | تُستخدم آخر حالة معروفة |
| انقطاع شبكة وزائر جديد تماماً | **مقفل** (الأحوط) |
| خطأ غير متوقع | يُفتح الموقع بعد ٨ ثوانٍ كحد أقصى |

## حدود الحماية — اقرأها بوضوح

هذه بوابة **ردع**، وليست تشفيراً. المواقع ملفات ثابتة على الاستضافة، ومَن يعرف
كيف يعطّل الجافاسكربت أو يقرأ مصدر الصفحة يستطيع رؤية المحتوى. الغرض منها:
منع العميل العادي (أو مطوّر يتصفّح بشكل طبيعي) من أخذ نسخة كاملة والتصفّح الحر،
وإعطاؤك مفتاح التحكّم والتفاوض.

**للحماية الحقيقية** (إن احتجتها لاحقاً) الخيار هو ألا يصل المحتوى للمتصفح أصلاً:
استضافة تدعم حماية على مستوى الخادم (Cloudflare Access / Netlify password)، أو
تسليم محتوى مشفّر يُفكّ بمفتاح يأتي بعد الفتح. قل لي وقتها وأنفّذها.
