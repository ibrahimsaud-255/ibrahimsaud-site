# نقل لوحات Apple Freeform إلى «الخرائط الذهنية»

Freeform لا يتيح قراءة قاعدة بياناته، وتصديره PDF يكسر تشكيل العربية (النقاط
تُرسم حروفاً منفصلة). لذلك المحوّل يأخذ من الـPDF **المواقع والأحجام والألوان
والأشكال والصور الأصلية**، ويقرأ **النصوص** بالتعرّف الضوئي المدمج في macOS (Vision).

1. في Freeform: افتح اللوحة ← File ← Export Board as PDF… واحفظ ملفات اللوحات في مجلد واحد.
2. شغّل: `./tools/freeform-import/run.sh ~/Desktop/freeform-pdfs`
3. في النظام: الخرائط الذهنية ← «استيراد» ← اختر `freeform-boards.json`.

إعادة الاستيراد آمنة: اللوحة المستوردة سابقاً (نفس الملف) تُتخطّى. الصور تُرفع
لحاوية `task-images` عند الدخول بحسابك، فلا تتضخّم بيانات النظام.

حدود معروفة: الروابط بين العناصر (connectors) تأتي خطوطاً مرسومة لا روابط ذكية،
والنص داخل الصور يبقى جزءاً من الصورة.
