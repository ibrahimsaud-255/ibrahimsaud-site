# دليل متجر «إبرة سارة»

متجر عرض خدمات الخياطة والتفصيل النسائي — يعمل كواجهة متجر كاملة (اختيار قطعة،
خامة، لون، مقاس، إضافات، شحن) لكن **بدون بوابة دفع**: الطلب يُرسل إلى واتساب
والدفع بتحويل بنكي.

## الصفحات

| الرابط | الوصف |
|---|---|
| `/sarah` | الواجهة: هيرو، المنتجات، الخامات، المقاسات، خطوات الطلب، الشحن، الأسئلة |
| `/sarah/products/<معرّف-المنتج>` | صفحة المنتج: معرض ٤ صور + التفاصيل + نموذج الطلب |
| `/sarah/sizes` | دليل المقاسات العالمية الكامل + حاسبة المقاس + طريقة القياس |
| `/sarah/order` | نموذج الطلب المستقل (يقبل `?product=معرّف-المنتج`) |

---

## ١) الملف الذي تُعدَّل منه كل الأشياء

كل محتوى المتجر في ملف واحد: **`src/lib/sarah.ts`**

### أ. بيانات المتجر (أعلى الملف)

```ts
export const sarah = {
  whatsapp: "966500000000",   // ← رقم واتساب المتجر (صيغة دولية بدون + وبدون صفر)
  instagram: "",               // ← رابط إنستقرام (اختياري)
  city: "الرياض",
  workHours: "السبت – الخميس، ١٠ص – ٩م",
  notice: "نسخة أولية من متجر «إبرة سارة» …",  // ← الإشعار المؤقت أعلى الموقع
};
```

> **مهم:** غيّري `whatsapp` أول شيء — الطلبات كلها تروح على هذا الرقم.
> ولإخفاء الإشعار المؤقت اجعلي `notice: ""`.

### ب. بيانات التحويل البنكي

```ts
export const bank = {
  bankName: "مصرف الراجحي",
  accountName: "إبرة سارة",
  iban: "SA00 0000 0000 0000 0000 0000",   // ← الآيبان الحقيقي
};
```

### ج. الأسعار

- سعر كل قطعة: الحقل `price` داخل `products`.
- فرق سعر الخامة: الحقل `priceDelta` داخل `fabrics` (`0` = مشمول بالسعر).
- أسعار الإضافات: `addOns`.
- رسوم الشحن لكل منطقة: `regions` (حقل `fee`).
- حدّ الشحن المجاني: `freeShippingOver` (`0` = تعطيل).
- رسوم التفصيل على المقاس للقطع ذات المقاسات العالمية: الثابت `CUSTOM_FIT_FEE`
  في `src/components/sarah/OrderForm.tsx` (حالياً ٨٠ ر.س).

## ٢) الصور — الحالة الحالية وكيف تُستبدل

**كل الخانات مليانة الآن** برسومات متجهة (SVG) مولّدة بالكود: قوامات القطع بألوان
الخامات الحقيقية، وسواتش خامات بملمس مولّد (نسيج كتان، لمعة ساتان، وبر مخمل،
نقشة دانتيل…). كلها بهوية واحدة، وحجمها كامل أقل من نصف ميجابايت.

لإعادة توليدها بعد أي تعديل على الألوان أو القوامات:

```bash
node scripts/generate-sarah-art.mjs
```

الألوان والقوامات تُعدَّل من الكائن `looks` و`fabricDefs` داخل
`scripts/generate-sarah-art.mjs`.

### استبدالها بصور فوتوغرافية

هذه الرسومات مرحلة أولى. متى ما جهزت الصور الحقيقية (تصوير أو توليد بالذكاء
الاصطناعي عبر أي أداة توليد صور)، ارفعيها في نفس المجلدات وعدّلي المسارات في
`src/lib/sarah.ts`. أي خانة تُترك `""` تظهر تلقائياً كمربّع منقّط مكتوب فيه المسار
المطلوب — فما تحتاجين تحفظين شيئاً.

| النوع | المسار | المقاس المقترح |
|---|---|---|
| صور الهيرو (٣) | `public/sarah/hero-1.webp` … `hero-3.webp` | ١٢٠٠×١٥٠٠ و١٢٠٠×١٢٠٠ |
| صور المنتج (٤ لكل منتج) | `public/sarah/products/<معرّف>-1.webp` … `-4.webp` | ١٢٠٠×١٥٠٠ (4:5) |
| صور الخامات | `public/sarah/fabrics/<معرّف>.webp` | ١٠٠٠×١٠٠٠ (مربّع) |

بعد رفع الصور، اربطيها في `src/lib/sarah.ts`:

```ts
// منتج
images: [
  "/sarah/products/abaya-classic-1.webp",
  "/sarah/products/abaya-classic-2.webp",
  "", ""            // خانات فاضية = يظهر مكان الصورة
],

// خامة
image: "/sarah/fabrics/nida.webp",
```

## ٣) إضافة منتج جديد

انسخي أي عنصر داخل `products` وغيّري:

```ts
{
  id: "معرّف-بالإنجليزي",       // يصير رابط الصفحة /sarah/products/<id>
  name: "اسم القطعة",
  category: "abaya",             // abaya | dress | jalabiya | daily | service
  tagline: "سطر تسويقي قصير",
  desc: "الوصف الكامل",
  price: 450,
  days: "٥–٧ أيام",
  sizing: "length",              // alpha = XS–4XL | length = ٥٢–٦٠ | custom = تفصيل
  fabrics: ["nida", "japanese-crepe"],
  addOns: ["hand-embroidery", "full-lining"],
  images: ["", "", "", ""],
  aiPrompt: "أمر توليد الصورة…",
  includes: ["ما يشمله السعر…"],
  featured: true,                // تظهر في «الأكثر طلباً» (اختياري)
}
```

لإضافة خامة جديدة: انسخي عنصراً من `fabrics` وغيّري `id` و`name` و`colors`
و`priceDelta`، ثم أضيفي المعرّف في قائمة `fabrics` داخل المنتجات التي تناسبها.

## ٤) نظام المقاسات المعتمد

ثلاثة أنظمة، والعميلة تختار بينها في نموذج الطلب:

1. **المقاسات العالمية بالحروف** — من `XS` إلى `4XL`، مربوطة بقياسات الجسم
   (صدر/خصر/ورك بالسنتيمتر) وبجداول التحويل العالمية. القاعدة المعتمدة:
   `US = EU − 32` و`UK = US + 4` (والمقاس الأسترالي = البريطاني).
2. **مقاسات الطول للعبايات** — من ٥٢ إلى ٦٠ بوصة، والمقاس = الطول الكلي من أعلى
   الكتف حتى الطرف السفلي، ويُختار حسب طول الجسم لا حسب مقاس الملابس.
3. **التفصيل على المقاس** — ١١ نقطة قياس مبنية على نقاط القياس المعتمدة عالمياً
   (ISO 8559 لقياسات الجسم).

كل هذا في `alphaSizes` و`lengthSizes` و`customMeasures` داخل `src/lib/sarah.ts`،
والموقع فيه حاسبة تقترح المقاس من القياسات (`suggestSize` / `suggestLength`).

## ٥) رحلة الطلب (كيف تشتغل فعلياً)

1. العميلة تجهّز الطلب في الموقع، والإجمالي يتحدّث لحظياً (قطعة + خامة + إضافات +
   تفصيل + شحن المنطقة).
2. تضغط **«إرسال الطلب في واتساب»** → يفتح واتساب على رقم المتجر برسالة جاهزة فيها:
   رقم الطلب، القطعة، الخامة واللون، المقاس أو القياسات كاملة، الإضافات، الكمية،
   الإجمالي، بيانات الشحن، وطريقة الدفع.
3. أنتِ تؤكّدين السعر النهائي.
4. العميلة تحوّل بنكياً وترسل صورة الإيصال → يبدأ التنفيذ.

يوجد أيضاً زر **«نسخ تفاصيل الطلب»** لو ما فتح واتساب تلقائياً.

> لا يطلب الموقع أي بيانات بطاقة، ولا يوجد أي بوابة دفع — هذا مقصود في هذه المرحلة.

## ٧) التشغيل والنشر

```bash
npm run dev     # التطوير: افتحي /sarah
npm run build   # بناء وتصدير ثابت (الموقع مُصدَّر static export)
```

ملاحظات:

- الموقع كله مُصدَّر ثابتاً، لذلك لا يوجد سيرفر يستقبل الطلبات — وهذا سبب اعتماد
  واتساب كوسيلة استلام.
- الروابط تنتهي بشرطة مائلة (`/sarah/order/`) بحكم إعداد `trailingSlash`.
