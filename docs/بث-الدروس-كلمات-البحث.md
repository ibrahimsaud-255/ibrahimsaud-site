# كلمات البحث — «برنامج بث الدروس العلمية»

خريطة الكلمات اللي يبحث فيها الناس، مجمّعة بالنيّة، وكلّ مجموعة لها صفحة واحدة تستهدفها
(مقال في المدوّنة أو صفحة البرنامج نفسها). كلّ المقالات تربط لـ`/lessons-broadcast/`
وتربط ببعض. المقالات في الكود: `src/lib/blog-lessons.ts` (قسم «بث الدروس العلمية» في المدوّنة).

> ملاحظة البحث (نوفمبر ٢٠٢٦): نتائج جوجل العربيّة لهالعبارات ضعيفة جدّاً — صفحات بثّ
> إسلام ويب، وأخبار الحرمين، وأدلّة عامّة عن يوتيوب. ما فيه دليل عربيّ عمليّ واحد متخصّص
> بالدروس العلميّة، فالمجال مفتوح لمن يكتب الأدلّة الحقيقيّة.

قواعد المحتوى: البرنامج مستقلّ (لا ذكر لأيّ برنامج أو محرّك تحته)، لا أسعار بالأرقام،
لا مشاكل تقنيّة معقّدة، ولا شركات إسرائيليّة.
