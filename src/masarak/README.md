# مسارك — منصّة القبول الجامعي

وحدة **مستقلة تماماً**: كل ما تحتاجه المنصّة موجود داخل `src/masarak/` ولا تستورد
شيئاً من بقيّة الموقع. لنقلها إلى مشروع آخر انسخ مجلدين فقط:

```
src/masarak/            ← الكود والبيانات والأنماط
public/masarak/logos/   ← شعارات الجامعات
```

ثم أضف صفحة من ثلاثة أسطر:

```tsx
// app/masarak/page.tsx
import Masarak from "@/masarak/Masarak";
export default function Page() { return <Masarak />; }
```

ولا تنسَ استيراد الأنماط مرّة واحدة (في `layout.tsx` الخاص بالمسار):

```tsx
import "@/masarak/masarak.css";
```

المتطلبات: React 19 و Next.js 16 (App Router). لا توجد أي حزمة خارجية، ولا
يعتمد `masarak.css` على Tailwind — هو CSS خالص.

**الخط:** المنصّة تستخدم خط «ثمانية» إن كان متاحاً في الموقع المضيف، وإلا تعود
تلقائياً إلى خط النظام (‏SF Pro‏ على أجهزة أبل). لتثبيت خط بعينه، غيّر
`font-family` في أول قاعدة `.masarak` داخل `masarak.css`.

## كيف تعمل الحسبة

### ١. النسبة الموزونة

لكل جامعة قائمة قواعد (`formulas`)، وتُطبَّق **أول قاعدة تنطبق شروطها** على
الطالب (المسار، الجنس، مجال التخصص). مثال جامعة الملك فيصل:

```ts
formulas: [
  { label: "المسار العلمي والصحي", tracks: ["sci"], weights: { hs: 30, qud: 30, tah: 40 } },
  { label: "المسار الأدبي (بدون تحصيلي)", tracks: ["lit"], weights: { hs: 60, qud: 40, tah: 0 } },
]
```

ولهذا تختلف نسبة الطالب نفسه من جامعة لأخرى — وهذا مقصود ومعروض في الواجهة.

### ٢. الحد التقديري للقبول

الجامعات **لا تُعلن** حدود القبول مسبقاً؛ فهي تنافسية وتتغيّر كل سنة حسب عدد
المتقدّمين والمقاعد. لذلك:

1. إن كان لدينا **رقم رسمي منشور** نستخدمه (حقل `knownCutoffs`)، ويظهر في
   الواجهة بوسم «رقم رسمي».
2. وإلا نشتقّه من نموذج خطّي:

```
الحد = 70 + (demand × 0.22) + selectivity(الجامعة)
```

**المعايرة:** ضُبط النموذج على نسب القبول الفعلية المنشورة لجامعة الإمام
عبدالرحمن بن فيصل (‏selectivity = 0‏)، ويطابقها بفارق أقلّ من ٠٫١ نقطة:

| التخصص | الرقم الرسمي | ناتج النموذج |
|---|---|---|
| المسار الصحي | ٩٠٫٠٢ | ٩٠٫٢ |
| علوم الحاسب | ٨٩٫١٣ | ٨٩٫١ |
| الهندسة | ٨٨٫٨٨ | ٨٨٫٩ |
| التمريض | ٨٧٫٢٠ | ٨٧٫٢ |
| إدارة الأعمال | ٨٤٫٧٥ | ٨٤٫٧ |
| الصحة العامة | ٨٣٫٨١ | ٨٣٫٩ |
| العمارة | ٨٣٫٣٤ | ٨٣٫٢ |

### ٣. الحكم على الفرصة

الفارق بين نسبة الطالب والحد (بالنقاط المئوية) — العتبات في `config.ts`:

| الفارق | الحكم |
|---|---|
| ‏+٣‏ فأكثر | فرصة قوية |
| ‏٠‏ إلى ‏+٣‏ | مرشّح جيد |
| ‏−٢٫٥‏ إلى ‏٠‏ | حدّي |
| أقل من ‏−٢٫٥‏ | بعيد |

## كيف تُحدِّث البيانات

**تعديل معادلة جامعة** — غيّر `formulas` في `data/universities.ts` وارفع
`confidence` إلى `"official"` مع رابط المصدر في `source`.

**إضافة نسب قبول حقيقية** — أضف الأرقام إلى `knownCutoffs` لتلك الجامعة:

```ts
knownCutoffs: { med: 91.4, cs: 88.2 }
```

هذه الأرقام تتجاوز النموذج التقديري وتظهر موسومة بـ«رقم رسمي». كلّما أضفت
أرقاماً حقيقية زادت دقّة المنصّة، بلا أي تغيير في الكود.

**ضبط تنافسية جامعة** — غيّر `selectivity` (‏−٨‏ إلى ‏+٥‏). كل نقطة = نقطة مئوية
واحدة على كل تخصصاتها.

**إضافة تخصص** — أضفه إلى `data/majors.ts` بمؤشر `demand` مناسب، ثم أضف
معرّفه إلى مصفوفة `majors` في كل جامعة تدرّسه.

**إضافة جامعة** — أضف عنصراً في `data/universities.ts`، ثم أضف عنوان مقالتها في
`scripts/masarak-logos.mjs` وأعد تشغيل السكربت لجلب شعارها.

## الشعارات

```bash
node scripts/masarak-logos.mjs
```

يجلب الشعارات من ويكيبيديا ويحفظها في `public/masarak/logos/` ويولّد
`data/logos.ts`. أي جامعة يفشل شعارها تظهر بحرفين من اسمها على لون هويتها،
فلا تنكسر الواجهة أبداً.

الشعارات ملك لأصحابها وتُعرض للتعريف بالجامعات فقط. إن رغب العميل في
الاستغناء عنها، احذف محتويات مجلد الشعارات — تعمل المنصّة كما هي بالأحرف.

## ما تحتاجه المنصّة لتصبح إنتاجية

النموذج الحالي دقيق في **المعادلات**، وتقديري في **حدود القبول**. أعلى ما يرفع
دقّتها:

1. أدلّة القبول الرسمية (PDF) لكل جامعة للعام الحالي — لتأكيد كل معادلة ورفع
   `confidence` إلى `official`.
2. نسب القبول الفعلية للسنة الماضية لكل تخصص — تُدخَل في `knownCutoffs`.
3. قوائم التخصصات المعتمدة لكل جامعة — لضبط مصفوفة `majors`.
