# مسارك — منصّة الإرشاد الجامعي

منصّة مدفوعة بكود تفعيل: الطالب يفعّل، يدخل درجاته، يخوض اختبار ميول علمي،
فتظهر له التخصصات التي **تناسبه** و**تقبله** في جامعات المملكة، ومعها الجامعات
التي تدرّس كل تخصص.

وحدة **مستقلة تماماً**: لا تستورد شيئاً من بقية الموقع، ولا تعتمد أي حزمة
خارجية، ولا Tailwind. لنقلها إلى مشروع آخر انسخ:

```
src/masarak/            ← الكود والبيانات والأنماط
public/masarak/         ← شعارات الجامعات + ملف الربط
supabase/masarak.sql    ← قاعدة أكواد التفعيل
```

ثم أضف صفحتين:

```tsx
// app/masarak/page.tsx
import Masarak from "@/masarak/Masarak";
export default function Page() { return <Masarak />; }

// app/masarak/admin/page.tsx
import Dashboard from "@/masarak/admin/Dashboard";
export default function Page() { return <Dashboard />; }
```

واستورد الأنماط مرّة واحدة في `layout.tsx` الخاص بالمسار:

```tsx
import "@/masarak/masarak.css";
```

المتطلبات: React 19 و Next.js 16 (App Router). **الخط:** تستخدم المنصّة خط
«ثمانية» إن كان متاحاً في الموقع المضيف، وإلا تعود لخط النظام (SF Pro على
أجهزة أبل).

## رحلة الطالب

```
كود التفعيل  →  درجاتك (٣ أرقام)  →  اختبار الميول (٧٥ عبارة)  →  النتائج
```

النتائج تجمع بعدين مستقلّين:

| البعد | مصدره | ما يجيب عنه |
|---|---|---|
| **يناسبك ٪** | اختبار الميول | هل يشبهني هذا التخصص؟ |
| **فرصتك** | النسبة الموزونة | هل تكفي درجاتي لدخوله؟ |

والطالب يقلب الترتيب بين «الأنسب لشخصيتك» و«الأصعب قبولاً».

## الأساس العلمي لاختبار الميول

### ١. الميول المهنية — نموذج هولاند (RIASEC)

ستة أنماط: العملي، البحثي، الإبداعي، الاجتماعي، الريادي، المنظّم. هو النموذج
الأكثر تحقّقاً في مطابقة الأشخاص بالمهن، وعليه تقوم أداة **O\*NET Interest
Profiler** الصادرة عن وزارة العمل الأمريكية.

٤٨ بنداً (٨ لكل نمط)، كل بند نشاط عمل يقيّمه الطالب على سلّم من خمس درجات —
وهي صيغة النسخة المختصرة من المقياس، مكتوبةً بالعربية ومكيَّفةً للسياق السعودي.

- Holland, J. L. (1997). *Making Vocational Choices* (3rd ed.).
- [O\*NET Interest Profiler Short Form — Psychometric Characteristics](https://www.onetcenter.org/dl_files/IPSF_Psychometric.pdf), USDOL/ETA.

> **إسناد مطلوب برخصة O\*NET:** تستفيد المنصّة من أدوات O\*NET لاستكشاف المهن
> الصادرة عن وزارة العمل الأمريكية (USDOL/ETA)، وقد كُيِّفت وتُرجمت هنا. لم
> تعتمد USDOL/ETA هذه التعديلات ولم تختبرها. O\*NET علامة مسجّلة لـ USDOL/ETA.
> النص معروض للطالب داخل بطاقة النتيجة.

### ٢. القيم المهنية — مراسي شاين

تسع قيم: التحكّم، الراحة، الاستقرار، التميّز، القيادة، المعنى، الإبداع،
العلاقات، الاحترام. ٢٧ بنداً (٣ لكل قيمة) بسلّم من أربع درجات بلا خيار محايد.

- Schein, E. H. (1990). *Career Anchors: Discovering Your Real Values.*

### ٣. حساب التوافق

لكل تخصص في `data/majorFit.ts` رمز هولاند ثلاثي وقائمة قيم يخدمها. التوافق =
**٦٥٪ ميول + ٣٥٪ قيم**، ويُحسب بجيب تمام الزاوية بين متجهَي الطالب والتخصص —
فيقيس تشابه *نمط* الاهتمام لا شدّته، ولا يُظلم طالب أجاب بتحفّظ على كل البنود.

## معادلات القبول وحدود القبول

### النسبة الموزونة

لكل جامعة قائمة قواعد، وتُطبَّق **أول قاعدة تنطبق شروطها** (المسار، الجنس،
المجال). مثال جامعة الملك فيصل:

```ts
formulas: [
  { label: "المسار العلمي والصحي", tracks: ["sci"], weights: { hs: 30, qud: 30, tah: 40 } },
  { label: "المسار الأدبي (بدون تحصيلي)", tracks: ["lit"], weights: { hs: 60, qud: 40, tah: 0 } },
]
```

ولهذا تختلف نسبة الطالب نفسه من جامعة لأخرى — وهذا معروض له بوضوح.

### حدود القبول

الجامعات **لا تُعلنها** مسبقاً؛ فهي تنافسية وتتغيّر كل سنة. لذلك:

1. إن وُجد **رقم رسمي منشور** يُستخدم (`knownCutoffs`) ويظهر بوسم «رقم رسمي».
2. وإلا يُشتق من نموذج خطّي: `الحد = 70 + (demand × 0.22) + selectivity`

**المعايرة:** ضُبط النموذج على نسب القبول الفعلية المنشورة لجامعة الإمام
عبدالرحمن بن فيصل (`selectivity = 0`)، ويطابقها بفارق أقلّ من ٠٫١ نقطة:

| التخصص | الرقم الرسمي | ناتج النموذج |
|---|---|---|
| المسار الصحي | ٩٠٫٠٢ | ٩٠٫٢ |
| علوم الحاسب | ٨٩٫١٣ | ٨٩٫١ |
| الهندسة | ٨٨٫٨٨ | ٨٨٫٩ |
| التمريض | ٨٧٫٢٠ | ٨٧٫٢ |
| إدارة الأعمال | ٨٤٫٧٥ | ٨٤٫٧ |
| الصحة العامة | ٨٣٫٨١ | ٨٣٫٩ |
| العمارة | ٨٣٫٣٤ | ٨٣٫٢ |

## تشغيل البيع — خطوة بخطوة

المنصّة تعمل بلا خادم في **وضع التجربة** (زرّ «جرّب المنصّة بلا كود») حتى
تربطها. لتشغيل البيع الحقيقي:

**١) أنشئ مشروع Supabase** على الحساب الذي ستملك عليه المنصّة (مجاني يكفي).

**٢) شغّل قاعدة البيانات:** افتح **SQL Editor** والصق `supabase/masarak.sql`
كاملاً ثم Run.

**٣) اضبط مفتاح اللوحة** (في نفس المحرّر، غيّر النص):

```sql
select public.masarak_set_admin_key('اكتب-مفتاحاً-طويلاً-هنا');
```

المفتاح لا يُخزَّن نصّاً ولا يُرسل في أي استجابة — تُحفظ تجزئته فقط.

**٤) اربط الواجهة:** من **Project Settings → API** انسخ الـURL والمفتاح
العلني (`publishable`/`anon`)، وأنشئ `public/masarak/backend.json`:

```json
{ "url": "https://xxxx.supabase.co", "key": "sb_publishable_..." }
```

> هذا الملف يُقرأ وقت التشغيل، فنقل المنصّة إلى حساب آخر لاحقاً = تعديل ملف
> واحد بلا إعادة بناء. (بديلاً، اكتب القيم في `config.ts` وأعد البناء.)

**٥) ولّد الأكواد:** افتح `/masarak/admin/`، أدخل المفتاح، حدّد العدد واسم
الدفعة والصلاحية، ثم **تنزيل CSV**.

**٦) ارفعها في سلة:** أنشئ منتجاً رقمياً من نوع «أكواد» وارفع ملف الـCSV
(عمود واحد اسمه `code`). سلة ترسل لكل مشترٍ كوداً مختلفاً تلقائياً.

### الأمان

- كل الجداول مقفلة بـ RLS **بلا أي سياسة** — المفتاح العلني لا يقرأ الأكواد
  ولا يعدّها.
- كل تعامل يمرّ عبر دوال `SECURITY DEFINER` تفحص شروطها بنفسها.
- الكود يُربط بجهاز واحد عند أول تفعيل؛ ومحاولة استخدامه على جهاز آخر تُرفض،
  بينما يعمل على الجهاز نفسه بعد مسح المتصفّح.
- نتائج الطلاب تُحفظ **مجهّلة** (بلا اسم ولا رقم ولا بريد) للإحصاء فقط.

## كيف تُحدِّث البيانات

**معادلة جامعة** — غيّر `formulas` في `data/universities.ts`، وارفع
`confidence` إلى `"official"` مع رابط المصدر في `source`.

**نسب قبول حقيقية** — أضفها إلى `knownCutoffs` لتلك الجامعة:

```ts
knownCutoffs: { med: 91.4, cs: 88.2 }
```

تتجاوز النموذج التقديري وتظهر موسومة بـ«رقم رسمي». كلّما أضفت أرقاماً حقيقية
زادت الدقّة، بلا أي تغيير في الكود.

**تنافسية جامعة** — غيّر `selectivity` (‏−٨‏ إلى ‏+٥‏). كل نقطة = نقطة مئوية
على كل تخصصاتها.

**تخصص جديد** — أضفه في `data/majors.ts` بمؤشر `demand`، وأضف بصمته في
`data/majorFit.ts`، ثم أضف معرّفه لمصفوفة `majors` في كل جامعة تدرّسه.

**جامعة جديدة** — أضفها في `data/universities.ts`، ثم أضف عنوان مقالتها في
`scripts/masarak-logos.mjs` وأعد تشغيل السكربت.

**بند اختبار** — عدّل `data/instrument.ts`. الأعداد تُحسب تلقائياً؛ لا شيء
آخر يحتاج تعديلاً.

## الشعارات

```bash
node scripts/masarak-logos.mjs
```

يجلبها من ويكي بيانات وويكيبيديا ويحفظها في `public/masarak/logos/` ويولّد
`data/logos.ts`. أي جامعة يفشل شعارها تظهر بحرفين من اسمها على لون هويتها،
فلا تنكسر الواجهة أبداً. الشعارات ملك لأصحابها وتُعرض للتعريف بالجامعات فقط.

## ما يرفع دقّة المنصّة

النموذج دقيق في **المعادلات**، وتقديري في **حدود القبول**. أعلى ما يرفعه:

1. أدلّة القبول الرسمية (PDF) لكل جامعة للعام الحالي — لتأكيد كل معادلة.
2. نسب القبول الفعلية للسنة الماضية لكل تخصص — تُدخَل في `knownCutoffs`.
3. قوائم التخصصات المعتمدة لكل جامعة — لضبط مصفوفة `majors`.
4. عيّنة من طلاب حقيقيين لمعايرة بنود الاختبار محلياً (تحليل ثبات وصدق).
